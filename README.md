# Exercícios de JavaScript (1 a 20)

Lista com 20 exercícios de fundamentos de JavaScript, com o enunciado em comentário e a resolução em cada arquivo.

## Temas

- Declaração de variáveis (`var`, `let`, `const`)
- Tipos de dados (`null`, `undefined`, números, strings)
- Operadores e expressões
- Template strings

## Como rodar

Requer [Node.js](https://nodejs.org/).

```bash
node atividade01.js
```

## Estrutura

`atividade01.js` a `atividade20.js`: um exercício por arquivo.
